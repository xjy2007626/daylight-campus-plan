# 日常有序

个人学习、午间训练、饮食与备忘录网站。无需构建，发布目录为 `dist/`。

## 数据

文字记录在访问者浏览器的 localStorage，照片在 IndexedDB。网站没有云数据库、照片识别服务或跨设备自动同步。发布包仅含程序和默认计划，不含使用过程中记录的照片、打卡或备忘。

迁移到新网址前，从旧网址导出备份，再到新网址的“备忘录 → 数据与设置”导入。旧文字备份不含照片；新完整备份包含照片。新网址无法直接读取旧网址的数据。

## 更新方式

有修改需求时，每周集中更新一次网站。没有修改需求时不自动更改计划或清空记录。部署新文件不更换存储键和照片库名称，保留同一网址上的现有记录。

## 验证

`node test-fitness.cjs` 检查旧数据迁移、训练日程冲突、10天复盘、预算计算、每日任务与便签保留。

发布使用相对资源路径和哈希路由，支持 GitHub Pages 项目子目录。
